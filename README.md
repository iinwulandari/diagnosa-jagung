# Aplikasi Skripsi - CornScan AI
Sistem Klasifikasi Penyakit Daun Jagung menggunakan CNN dan Flask.

## Cara Menjalankan:
1. Install library: `pip install -r requirements.txt`
2. Jalankan aplikasi: `python app.py`
3. Buka di browser: `http://127.0.0.1:5000`
